<p class="td-lead">TrustDeck is an open-source platform for pseudonymization and identity management in medical research. It supports trusted third parties in interactive work and integrates into research infrastructures and data pipelines.</p>

## Where to start

| You are … | You want to … | Start here |
|---|---|---|
| Staff at a trusted third party or in a project | manage projects, entities and pseudonyms in the browser | [User Docs](/trustdeck-setup/user/) |
| Developer | integrate TrustDeck through its REST API | [Quickstart](/trustdeck-setup/quickstart/), then [Authentication](/trustdeck-setup/rest-api/authentication/) |
| Java developer | use the Java client instead of plain HTTP | [Java client](/trustdeck-setup/java-client/getting-started/) |
| Operator | install TrustDeck and set up the first administrator | [Deploy](/trustdeck-setup/deploy/) |
